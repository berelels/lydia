install in
a minute

Click a package to download it (x64; ARM64 and older versions on GitHub). The .deb is the recommended one. Everything on GNOME 42 to 51; the island and most tabs on Cinnamon, MATE, XFCE and KDE.

.deb ↓recommended Ubuntu, Debian, Mint, Pop!_OS, Zorin sudo apt install ./lydia_1.1.1_amd64.deb
.rpm ↓ Fedora, openSUSE sudo dnf install ./lydia-1.1.1.x86_64.rpm
Flatpak ↓ Any distro with Flatpak flatpak install ./Lydia-1.1.1-x86_64.flatpak
AppImage ↓ Any other distro chmod +x Lydia-1.1.1.AppImage
